### Capstone Project: ShopSphere
**[ShopSphere E-Commerce System](./Project/ShopSphere)** is a complete Java-based management system utilizing an N-Tier architecture[cite: 67]. 
* **Web Frontend:** JSP, HTML5, Bootstrap, JSTL, Expression Language (EL).
* **Backend Layer:** Jakarta Servlets, JDBC, MySQL.
* **Modules Included:** Swing Admin Panel, RMI Inventory Service, and Socket-based Client-Server communication.
